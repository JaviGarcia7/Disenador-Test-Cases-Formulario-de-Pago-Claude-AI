📋 Correcciones Aplicadas (v2):

  • ✅ MCP falla terminal: 3 reintentos + backoff → si fallan → "Error: MCP sin recuperación" (Fin ERROR)
  • ✅ Revisor timeout explícito: Compuerta "Timeout >30s?" → Flag: not-reviewed, asume aprobado
  • ✅ Validación hallucinations: Guardrail "validar_edge_case" → si edge case no existe en catálogo → rechaza caso
  • ✅ Especialista en Cobertura: Subagente paralelo que detecta top 3 gaps (vs 0 en v1)
  • ✅ Feedback en todos los finales: Entrada rechazada, MCP error, hallucination, data-exposure-risk, Product Owner rechaza
  • ✅ Frenos explícitos: Compuerta "¿Frenos? (iter=3, tokens)" → si SÍ → publicar parcial
  • ✅ Aprobación batch: Product Owner revisa todo y aprueba/rechaza (loop back si NO)

🔍 Problemas Detectados y Resueltos:

Problema Ubicación v1 Solución v2
Loop esperando → nunca llega MCP reintentos sin terminal Terminal explícita: "Error MCP" (Fin ERROR)
Camino sin respuesta al usuario Guardrail rechaza → FIN (sin mensaje) Todos los FIN tienen flag/error ("Error: HU inválido", etc.)
Revisor timeout silencioso No modelado Compuerta explícita "Timeout?" → Flag: not-reviewed
Especialista en Cobertura falta No aparecía en flujo Subagente paralelo: "Top 3 gaps" (flujo paralelo)
Hallucinations de edge cases No había validación Guardrail "validar_edge_case" → rechaza si no existe
